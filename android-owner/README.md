# iMenu Partner for Android

تطبيق Android native لإدارة تقييمات ومنتجات وأقسام مطعم المالك من نفس بيانات موقع iMenu.

## تشغيل وبناء التطبيق

1. أنشئ تطبيق Android في مشروع Firebase الخاص بك باستخدام package name: `com.imenu.owner`، وفعّل Firebase Cloud Messaging. نزّل `google-services.json` وضعه في مجلد `android-owner/app/`؛ يقرأ Gradle القيم منه تلقائيًا.
2. إذا لم يتوفر ملف الإعداد أثناء البناء، أضف القيم التالية إلى ملف `gradle.properties` الخاص بمستخدم البناء (وليس إلى Git):

   ```properties
   imenuFirebaseApiKey=...
   imenuFirebaseAppId=...
   imenuFirebaseProjectId=...
   imenuFirebaseSenderId=...
   ```

   تجد القيم في Firebase Console ضمن إعدادات المشروع وتطبيق Android المسجل.
3. في Render، افتح خدمة `I-menu` ثم **Environment**، وأضف متغيرًا سرّيًا باسم `FIREBASE_SERVICE_ACCOUNT_JSON` بقيمة JSON لحساب خدمة من نفس مشروع Firebase مع صلاحية إرسال رسائل Firebase Cloud Messaging. احفظ التغيير وأعد نشر الخدمة. **لا تضع المفتاح الخاص في التطبيق أو المستودع أو ملف `.env` المتعقّب.**
4. افتح `android-owner` في Android Studio، ثم شغّل التطبيق أو ابنِ APK.
5. سجّل الدخول من الهاتف بحساب مالك المطعم، واسمح بالإشعارات عند الطلب.

عند إضافة تقييم، يرسل السيرفر رسالة Firebase Cloud Messaging مباشرة إلى أجهزة المالك المسجلة. لا يعتمد وصولها على بقاء التطبيق مفتوحاً؛ قد يظل Android أو مزود الشبكة يؤخر الإشعار في بعض أوضاع توفير الطاقة. يلزم إعداد Firebase في التطبيق والسيرفر لتفعيل الإرسال الفوري.

التطبيق يستخدم واجهات الموقع الحالية؛ تعديل المنتجات والأقسام يكتب إلى نفس قاعدة البيانات والتخزين المستخدمين للموقع، ويرسل الموقع تحديث المنيو كالمعتاد. أرقام الدعم الفني ورابط Facebook تُقرأ من إعدادات التواصل المنشورة (`/api/v1/site/public`)، ويلزم إدخالها في إعدادات الموقع.

يتصل التطبيق تلقائياً بـ `https://www.imenueg.com` ولا يطلب إدخال رابط الموقع. يعتمد على تأكيد Android لاتصال الإنترنت، ويتحقق دوريًا من إمكانية الوصول الفعلية لخدمة iMenu؛ ويعرض حوارًا لإعداد الاتصال أو إعادة المحاولة عند انقطاعه. تحميل المنتجات يجري بالتوازي مع الأقسام، وتظهر المنتجات على دفعات لتسريع العرض. يمكن البحث عن المنتجات، فتح منتجات أي قسم بالنقر عليه، إظهار المنتجات أو إخفاؤها، تعديل اسم المنتج وإدارة أحجامه وأسعاره، أو حذفه بعد التأكيد؛ وتُزامَن التغييرات مع الموقع. من صفحة التقييمات في التطبيق أو لوحة المالك على الموقع يمكن إظهار التعليق أو إخفاؤه من صفحة الموقع دون حذف التقييم أو تغيير متوسط التقييمات. يتطلب تفعيل إخفاء التعليقات أن يضيف الخادم عمود `isCommentVisible` تلقائيًا عبر `DATABASE_URL` أو `SUPABASE_DB_URL`. تسجيل الدخول يقبل حساب المالك فقط ولا يحفظ كلمة المرور. يمكن للمالك تسجيل الخروج وحذف تقييم منفرد بعد تأكيد العملية. يُحفظ رمز الجلسة محلياً على الجهاز مع استثنائه من النسخ الاحتياطي.

يتطلب البناء Android Studio أو Gradle 8.9+ وJDK 17 وAndroid SDK Platform 35، واتصالاً بمستودعات Google وMaven لتنزيل الاعتماديات.
