# iMenu

نظام كاشير وإدارة متكامل للمطاعم والكافيهات: طاولات، مطبخ، طباعة حرارية، مخزون، شيفتات وتقارير، بالإضافة لمنيو رقمي للعملاء وتطبيق Android للمالك.

الموقع: https://www.imenueg.com

## المكونات

- `server.js` — سيرفر Express: واجهات API، المصادقة، الطلبات المباشرة (Socket.IO)، الإشعارات الفورية (Firebase Cloud Messaging وWeb Push)، والتكامل مع Gemini لتوليد المنيو من الصور.
- `public/` — واجهات الويب: صفحة الهبوط، المنيو الرقمي، لوحة تحكم المالك، لوحة المشرف، صفحات البيع والاشتراك.
- `android-owner/` — تطبيق Android للمالك (إدارة المنتجات والأقسام والتقييمات واستقبال الإشعارات).

## التشغيل محليًا

1. ثبّت الاعتماديات: `npm install`
2. انسخ `.env.example` إلى `.env` واملأ القيم (قاعدة البيانات، JWT، Cloudinary، مفاتيح الإشعارات). لا تضع `.env` في المستودع أبدًا.
3. شغّل السيرفر: `npm start` (أو `nodemon server.js` أثناء التطوير)

بيانات الدخول للوحة المشرف تُضبط من متغيرات البيئة، وحسابات المطاعم تُنشأ من لوحة المشرف.

## النشر

السيرفر منشور على Render ويُحدَّث تلقائيًا مع كل دفع إلى `main`. متغيرات البيئة تُدار من إعدادات الخدمة على Render.
