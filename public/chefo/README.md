# شيفو (Chefo) — مساعد iMenu ثلاثي الأبعاد

مجلد جاهز للتركيب على موقع imenueg.com. لا يعدّل أي ملف من ملفات الموقع.

## التركيب (خطوتان)

1. انسخ مجلد `chefo/` كما هو إلى جذر الموقع (بجانب `index.html`).
2. أضف هذا السطر في `index.html` قبل `</body>` مباشرة:

```html
<script src="/chefo/chefo.js" defer></script>
```

هذا كل شيء. شيفو يظهر فوق الصفحة الحالية بدون أي تغيير في شكل الموقع أو كوده.

## محتويات المجلد

| الملف | الوظيفة |
|---|---|
| `chefo.js` | كل المنطق: الشيف ثلاثي الأبعاد، بوابة "دوس وابدأ"، التثبيت بجانب اللوجو عند النزول، الجمل لكل قسم، دعم عربي/إنجليزي |
| `chefo.css` | تنسيق الغلاف والبوابة والفقاعة فقط (لا يلمس تنسيق الموقع) |
| `three.min.js` | مكتبة three.js مستضافة ذاتياً (لا روابط خارجية) |
| `audio/hero.mp3` | تسجيل الترحيب — **مؤقت حالياً بالجملة القديمة، سيُستبدل بالتسجيل الجديد الذي يعرف شيفو نفسه بالاسم** |
| `audio/features.mp3` | تسجيل قسم المميزات |
| `audio/steps.mp3` | تسجيل قسم الخطوات |
| `audio/partners.mp3` | تسجيل قسم الشركاء |
| `audio/contact.mp3` | تسجيل قسم التواصل |

## استبدال تسجيل الترحيب

عند وصول التسجيل الجديد: ضعه مكان `audio/hero.mp3` بنفس الاسم. لا حاجة لتغيير أي كود.
(لو التسجيل ناقص أو لم يعمل لأي سبب، شيفو يكمل تلقائياً بصوت الموبايل — لا يوجد صمت.)

## الإزالة

احذف سطر الـ`<script>` من `index.html`، واحذف مجلد `chefo/`. الموقع يرجع كما كان بالضبط.

## ملاحظات

- اللغة تتبع زر اللغة في الموقع نفسه لحظياً (عربي/إنجليزي)، والاتجاه يتبعه (يمين/يسار).
- يعمل على الموبايل والديسكتوب. الصوت يبدأ بعد أول ضغطة (سياسة المتصفحات).
- الدومين الأساسي بدون www (‏imenueg.com) لا يعمل حالياً على DNS — الموقع يعمل على www.imenueg.com.
